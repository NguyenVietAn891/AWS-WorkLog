### Week 6 Achievements:
* Understood and practiced using Lambda functions to interact with S3 and DynamoDB.
* Built a basic Frontend that calls APIs through API Gateway.
* Mastered the deployment process of Serverless applications using AWS SAM (Serverless Application Model).
* Successfully configured user authentication using Amazon Cognito.
* Set up a static website on S3 with SSL/TLS encryption.
* Understood the asynchronous processing flow using SQS and SNS for order management scenarios.
* Implemented an automated CI/CD pipeline for Lambda source code using CodePipeline.
* Used CloudWatch and X-Ray to monitor performance, trace requests, and debug Serverless applications.
* Gained an overview of AWS AppSync and the application of GraphQL in Serverless architectures.
